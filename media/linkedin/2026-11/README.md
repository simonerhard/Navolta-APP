# Navolta AG – LinkedIn-Bildablage (November 2026)

Diese öffentliche Bildablage ist für die 37 bestehenden LinkedIn-Entwürfe der Unternehmensseite **Navolta AG** vorgesehen.

## Vorgehen
1. Die 37 JPG-Dateien aus `Navolta_37_Buffer_Bilder_GitHub_Upload.zip` entpacken.
2. Im Repository `simonerhard/Navolta-APP` unter `media/linkedin/2026-11/` alle JPG-Dateien per **Add file → Upload files** hochladen und committen.
3. Die mitgelieferte `Buffer_Zuordnung_37.csv` enthält für jeden Beitrag die Buffer-ID, den passenden Bilddateinamen und die künftige direkte Bild-URL.
4. Erst nach dem Upload und einem URL-Test die entsprechenden Bild-URLs an die Buffer-Entwürfe anfügen.

## Direkte Medien-URLs
`https://raw.githubusercontent.com/simonerhard/Navolta-APP/main/media/linkedin/2026-11/DATEINAME.jpg`

**Wichtig:** Die Links auf Bilder funktionieren erst nach dem tatsächlichen Upload. Die jetzige Einrichtung veröffentlicht keine LinkedIn-Beiträge.

Original-Navolta-Logo und Corporate Design bleiben in den vorbereiteten Grafiken erhalten.
