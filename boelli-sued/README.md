# Bölli Süd · Navolta Pendenzencockpit

[App auf GitHub Pages öffnen](https://simonerhard.github.io/Navolta-APP/boelli-sued/)

Die App läuft im Browser. Das Projektpaket wird lokal als ZIP eingelesen. Die Pendenzen, Unterlagen, Fotos und Bearbeitungen werden im Browserprofil gespeichert. Jeder Browser hat seinen eigenen Stand. Excel und PDF lassen sich herunterladen und Outlook kann eine vorbereitete E-Mail mit den Berichten öffnen.

Unter `source/` liegt der Code der ursprünglich geschützten Variante. Der Einstieg für GitHub Pages liegt in `index.html`.
