Anleitung und Datensicherung

In Dalux Field → Aufgaben → alle relevanten Filter entfernen → Mehr → Exportieren → Gesamte Liste → Excel. Alle benötigten Spalten sichtbar machen. Excel öffnen und als CSV UTF-8 speichern. CSV hier importieren. Unbekannte Status werden nicht als erledigt gewertet. Bei erneutem Import werden vorhandene Datensätze mit gleicher ID und gleichem Projekt aktualisiert; vorher Sicherung erstellen. Ohne ID wird eine neue lokale ID vergeben. Originalspalten bleiben in der JSON-Sicherung enthalten.

Abmeldungen und Fotos werden im Browser dieses Geräts gespeichert und können per JSON auf ein anderes Gerät übernommen werden. PDF-Nachweise lassen sich zur Weitergabe speichern. Der Prüfstatus gilt im Cockpit. Dalux bleibt schreibgeschützt. Quelle und Cockpit-Status bleiben nachvollziehbar. Keine automatische Dalux-Synchronisation, keine serverseitige Speicherung. JSON-Sicherungen können manuell auf SharePoint abgelegt werden. PDF über den Druckdialog speichern. Management-Mail öffnet einen Entwurf ohne Anhang.
